# Auto Picture-in-Picture — Implementation Notes

**Date:** 2026-02-26
**Status:** Working

## What it does

When PiP mode is set to **Auto**, aigent automatically opens a floating
Document PiP window when the user switches to another tab. The PiP closes
when the user returns to the aigent tab.

## How it works

### Chrome's requirement

Chrome 134 fires the Media Session `enterpictureinpicture` action handler on
tab switch if **all** of these conditions hold:

1. A handler is registered via `navigator.mediaSession.setActionHandler('enterpictureinpicture', fn)`
2. `navigator.mediaSession.playbackState === 'playing'`
3. Media has been **audible** within the last 2 seconds (non-zero waveform energy)
4. The site has "Automatic picture-in-picture" permission set to **Allow**
   (Chrome prompts the user the first time; MEI threshold is waived once allowed)

### The looping tone trick

A 1-second 440 Hz sine wave at amplitude 0.005 is generated via
`OfflineAudioContext` into a WAV blob. This is played on loop at
`volume=0.001` through a hidden `<audio>` element.

- 0.005 amplitude = technically non-zero waveform → satisfies Chrome's
  "audible within last 2 seconds" check
- `volume=0.001` = −60 dB relative to full volume → completely inaudible

Audio starts on the first click or keydown (required by Chrome's autoplay
policy — muted audio can autoplay, but we need `volume > 0`).

### Open/close lifecycle

- **Open:** Media Session handler fires on tab switch → `createDocPiPWindow()`
  opens a Document PiP window (420×720) containing an iframe to `/`
- **Close:** `visibilitychange` fires when the aigent tab becomes visible
  again → `pipWindowRef.current.close()`

## What didn't work (and why)

| Approach | Why it failed |
|---|---|
| Silent Web Audio (`gain=0`) | Chrome's "audible" check requires non-zero waveform amplitude |
| Canvas `captureStream()` video | Chrome 134 media path requires audio, not video |
| `getUserMedia` mic stream | Chrome 120 video-conferencing path requires camera/screenshare too, not mic alone |
| `chrome.scripting.executeScript` → `requestWindow()` | Injected scripts don't carry user-gesture context |
| `chrome.tabs.sendMessage` → page listener | Pages don't have `chrome.runtime` unless a content script is present |

## Settings

- **`AIGENT_PIP_MODE`**: `'auto'` | `'manual'` (default: `'manual'`)
- First-time setup: Chrome will prompt "Allow automatic picture-in-picture for
  localhost:3141?" — click Allow. After that it works automatically.

## Production notes

On a real domain with real users, Chrome builds up Media Engagement Index (MEI)
over time. Once MEI threshold is exceeded, Chrome prompts automatically. The
explicit "Allow" permission waives the MEI requirement entirely.
